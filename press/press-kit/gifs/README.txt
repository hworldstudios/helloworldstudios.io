GIFs go in this folder.

Anything dropped here shows up automatically in the GIFs section of
https://helloworldstudios.io/press - no code changes needed.

Naming: lowercase kebab-case, e.g.
    beltfed-swarm-impact.gif
    beltfed-belt-to-barrel.gif
    beltfed-flamethrower.gif
    beltfed-upgrade-pick.gif
    beltfed-nexus-falling.gif

GIFs are served as-is (no thumbnails) so the animation survives, so keep
each one under a few MB.

Once a GIF is in, delete its matching "TODO:" line from ../../presskit.md.
That one file feeds both the press page and presskit.html in this kit.
